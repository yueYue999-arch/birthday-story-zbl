# 朱博乐 · 生日快乐

A personal interactive birthday gift. This repository contains only the deployable static website and its third-party notices.

Open https://yueyue999-arch.github.io/birthday-story-zbl/ and enter 朱博乐.

This is a personal gift demonstration, with no accounts, payments, analytics or server-side data collection. Reading progress is stored only in the visitor's browser. No source archive, local account data or development credentials are included.
